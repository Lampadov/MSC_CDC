# Флешка + WebUSB для К1986ВЕ9х

Плата определяется как USB-диск. На диске лежит веб-страница управления этой же платой: откройте `index.htm` прямо с флешки в Chrome или Edge, нажмите **Подключить плату**, и страница по WebUSB управляет светодиодами, показывает кнопки и температуру, а ещё в ней есть змейка. Ничего устанавливать и скачивать не нужно: ни драйверов, ни сервера, ни интернета.

## Запуск

1. Откройте `USB_MSC_WEBUSB.uvprojx` в Keil, соберите и прошейте плату.
   - Если Keil не находит `MDR32FxQI_adc.h`: *Manage Run-Time Environment* -> *Drivers* -> галочка **ADC**. Без АЦП задайте в `main.c` `#define USE_ADC 0`.
2. Подключите плату к USB. Появится диск `Milandr WEB` (только чтение) с файлами `index.htm`, `app.js`, `README.TXT`.
3. Откройте `index.htm` с этого диска в Chrome или Edge и нажмите **Подключить плату**.

Страница с `file://` получает доступ к WebUSB в Chrome и Edge. В Firefox и Safari WebUSB нет.

## Как это устроено

- Составное устройство: интерфейс 0 - флешка (MSC, EP1 OUT / EP2 IN), интерфейс 1 - vendor-класс для WebUSB (одна точка EP3 IN).
- Диск лежит во флеш-памяти как готовый образ FAT12 (`src/disk_image.c`, около 15 КБ), оперативная память под него не нужна. Запись запрещена.
- Образ создаёт `tools/make_disk.py` из каталога `web/`. На диск попадают уменьшенные копии файлов (без комментариев и отступов): так образ занимает около 15 КБ вместо 21 КБ, и проект помещается в 32 КБ бесплатной версии Keil. Исходники в `web/` остаются читаемыми. После правки страницы выполните
  ```
  python tools/make_disk.py
  ```
  и пересоберите проект. Имена файлов на диске только 8.3: `web/index.html` лежит как `index.htm`.
- Windows подключает драйвер WinUSB к интерфейсу 1 сама, по Microsoft OS 1.0 (строка `0xEE`, Compatible ID, GUID интерфейса). Флешкой занимается штатный драйвер.
- Браузер не даёт занять интерфейс флешки (защищённый класс), поэтому для WebUSB выделен отдельный vendor-интерфейс.
- Точек OUT для команд не осталось: у контроллера четыре точки, две заняты флешкой. Страница отправляет команду светодиодам vendor-запросом на нулевую точку: `bRequest 0x10`, `wValue` - маска светодиодов, адресат - интерфейс 1.

Кадр состояния платы (EP3 IN, little-endian, каждые 20 мс и сразу при нажатии кнопки): `01` `кнопки` `светодиоды` `АЦП (2 байта)` `мс с запуска (4 байта)`. Биты кнопок: SELECT, UP, DOWN, LEFT, RIGHT. Биты светодиодов: VD3, VD4.

## Если Windows не подключила WinUSB

Windows запоминает результат для связки VID/PID/bcdDevice. Если ранее плата уже определялась с другими дескрипторами, измените `USB_PID` в `src/usb_descriptors.c` (и `USB_VID` в `web/app.js`, если менялся VID) и пересоберите образ.
