# WebUSB-демо для К1986ВЕ9х

Плата подключается к веб-странице прямо из браузера (Chrome / Edge): без установки драйверов и без прав администратора.
Страница показывает «живую» плату: кнопки и светодиоды повторяют реальные, а чип светится, если показания датчика температуры отклонились (коснитесь микроконтроллера пальцем).

## Запуск

1. Откройте `USB_WEBUSB.uvprojx` в Keil, соберите и прошейте плату.
   - Если Keil не находит `MDR32FxQI_adc.h`: *Manage Run-Time Environment* -> *Drivers* -> поставьте галочку **ADC**.
   - Без АЦП: в `main.c` задайте `#define USE_ADC 0` (вместо АЦП будет «треугольник»).
2. Подключите плату к USB. Windows сама подключит драйвер WinUSB (несколько секунд).
3. В папке `web` запустите любой локальный сервер, например:
   ```
   cd web
   python -m http.server 8000
   ```
4. Откройте в Chrome или Edge `http://localhost:8000` и нажмите **Подключить плату**.

WebUSB работает только на `https://` или `http://localhost`. Для публикации страницы положите `web/` на любой https-хостинг (например, GitHub Pages).

## Что умеет страница

- **Змейка**: управляется кнопками платы, SELECT запускает игру и ставит её на паузу. Яблоко зажигает VD4, проигрыш зажигает VD3.
- **Пианино**: каждая кнопка платы играет ноту, светодиоды мигают в такт.
- **Огни и азбука Морзе**: бегущий огонь, мигание, «маяк», и передача введённого текста (русского или латинского) светодиодом VD3.
- **График АЦП** с выгрузкой отсчётов в CSV.

Прошивка при этом не меняется: всё это делает страница из кадров состояния и команды управления светодиодами (протокол ниже). Логика игры и азбуки Морзе вынесена в чистые функции в начале `web/app.js`, их можно запускать под Node.

## Как это устроено

- Vendor-интерфейс с двумя bulk-точками: EP1 OUT (команды) и EP2 IN (данные).
- Протокол (little-endian):

  | Направление | Кадр |
  |---|---|
  | плата -> страница, каждые 20 мс и сразу при нажатии кнопки | `01` `кнопки` `светодиоды` `АЦП (2 байта)` `мс с запуска (4 байта)` |
  | страница -> плата | `01` `светодиоды` |

  Биты кнопок: SELECT, UP, DOWN, LEFT, RIGHT. Биты светодиодов: VD3, VD4.
- Измеряется встроенный датчик температуры (канал `ADC_CH_TEMP_SENSOR`). Чтобы измерять вывод, укажите другой канал в `adc_init()`.

### Как Windows подключает WinUSB сама

Используется Microsoft OS 1.0 (`src/usb_descriptors.c`):

1. Хост читает строку `0xEE`: в ней `MSFT100` и код vendor-запроса.
2. По этому коду он запрашивает Compatible ID. Плата отвечает `WINUSB`, и Windows подключает встроенный `winusb.sys`.
3. Вторым запросом хост получает GUID интерфейса, по нему браузер находит устройство.

Эти запросы приходят на EP0, поэтому ответы длиннее 64 байт уходят несколькими пакетами (свойство GUID занимает 142 байта).

## Если не подключается

- Другая программа держит устройство (например, открытая вкладка с этой же страницей): закройте её.
- Жёлтый знак в диспетчере устройств, «Код 28» (нет драйвера) или «Код 10» (драйвер не запустился): Windows запоминает ответы платы для связки VID/PID/bcdDevice. Если когда-то плата отвечала неверно, после исправления Windows может не спросить заново. Смените `USB_PID` (или `bcdDevice`) в `usb_descriptors.c`, прошейте плату и переподключите её.
- Linux: нужно правило udev для `idVendor=cafe`, например `SUBSYSTEM=="usb", ATTR{idVendor}=="cafe", MODE="0666"`.
- Подсказки «Открыть страницу» при подключении (WebUSB landing page) нет: для неё нужны BOS-дескриптор и USB 2.1, а плата использует более простой `bcdUSB` 2.00.
